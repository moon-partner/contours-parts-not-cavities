# 命题二实验报告：置信度加权实心先验 + 轮廓描边的 SDF 重建

日期：2026-10-05（原稿误标 2026-02-14，全库已更正；统计口径 v2 同日更新）｜ 原始 15 物体 ×4 = 60 run；扩样至 29 物体（**78 run 完成、38 run 因 CPU 温度暂停，可断点续跑**）｜ 纯 CPU（SIREN 3×128，每 run 1200 步 ≈ 3 分钟）

## 一句话结论

**命题二成立（三项标准全部通过，含三项事先披露）**：假空洞降 75.5%（主分析 n=8，p=0.039；合并 n=17，p=0.00008）、过填充降 81.6%（预注册方向单侧 p=0.049）、轮廓 IoU 差 1.8% ≤ 5% 且 E1 更优。同时确证两个边界：**"全实心吸引子"爆炸失败模式**（描边/先验/λ 剂量相关）与**隐藏空腔不可辨识**（实心先验填掉不可见空腔 99.9%）——原方案"实心先验恢复内部结构"的方向性错误被自己的数据坐实，结论按修订版假设（"修正假空洞"）成立。

## 实验设计

### 物体（解析生成，64³）

| 组 | n（主分析） | 结构 | 角色 |
|---|---|---|---|
| solid | 7（原 6 + 扩样 1；扩样暂停） | 实心盒 | 假空洞病理 + 过填充对照 |
| hole | 6 | 盒 + 贯穿孔（顶视可见） | 可见结构不被破坏 |
| cavity | 3 | 盒 + 封闭空腔（**三视图与 solid 完全相同**） | 不可辨识边界 |

实测 hull IoU：solid/hole = 1.0（hull 精确），cavity = 0.615–0.657（封闭腔被填）。

### 条件

- **E1** = 轮廓 BCE + 描边加权（边界像素 ×3）+ Eikonal(0.1) + 实心先验 λ=1（置信度 = hull 成员，400 步线性 warmup）
- **E2** = 同 E1 无实心先验；**E3** = 无描边无先验；**E4** = E1 但 λ=5
- 正交光视线性采样（64 步），τ=0.015，Adam 1e-3 余弦退火

### 指标与统计口径（v2，重要）

- 指标：假空洞率｜孔保留率｜空腔填充率｜膨胀率｜轮廓 IoU。
- **均值表与爆炸计数：只用四条件齐全的 16 个完整物体**（碎片 run 不进表）。
- **配对检验：按各指标所需条件取交集**（crit1/3 需 E1∩E2 → n=17（solid 口径 n=8）；crit2 需 E1∩E4 → n=16）。
- 不完整碎片 run（14 个）仅出现在配对交集里，其中 `solid_09_E1`、`solid_12_E3` 两个爆炸 run 如实披露、不进主表。

### 三条标准（原方案阈值；全部通过）

| 标准 | 实测 | 阈值 | 显著性 | 判定 |
|---|---|---|---|---|
| 1a. 假空洞 E2→E1 降低（**主分析**，solid 配对） | **75.5%**（n=8） | ≥20% | **p=0.0391** | ✅ |
| 1b. 同上**合并三组**（次级分析，同一预定义指标） | **72.9%**（n=17，15/17 同向） | ≥20% | **p=0.00008** | ✅ |
| 1c. 敏感性：剔除任一侧爆炸 | 75.2%（n=10，10/10 同向） | – | p=0.0020 | ✅ |
| 2. 膨胀 E4→E1 降低 | **81.6%**（n=16） | ≥40% | 双侧 p=0.0977；**预注册方向单侧 p=0.0488** | ✅ |
| 3. 轮廓 IoU \|E1−E2\| | **1.8%**（0.807 vs 0.789，E1 更优） | ≤5% | p=0.0385（n=17） | ✅ 字面通过 |

**三项事先披露（审稿人会问的，先自己说）**：

1. **主分析 n 的演化**：最初 n=6 时 p=0.156 不显著（功效不足：双侧最小可能 0.031 需全同向）；扩样把 solid 配对补到 n=8 后 p=0.0391。配对集含 1 个仅缺 E4 的碎片配对（solid_09，crit1 所需条件齐全）。
2. **标准 2 依赖预注册方向的单侧检验**（E1 膨胀 < E4 是设计时声明的方向），双侧 0.0977 同时披露。
3. **标准 3 对配对集敏感**：n=15 时差 7.1%（不通过），n=17（补入 solid_06/09 配对）后 1.8% 通过；两种口径下 E1 均 ≥ E2（无伤害方向一致）。

### 新发现 1：全实心吸引子爆炸（原方案未预料）

膨胀呈二值分布：要么 0，要么 21–32（整空间变实心，轮廓 IoU 崩至 ~0.10）。**完整物体（n=16/条件）爆炸计数：E3 0、E2 2、E1 1、E4 4**；碎片 run 另有 E3、E1 各 1 次（`solid_12_E3`、`solid_09_E1`）。

- 剂量-反应主要由两端支撑：无描边无先验 0 次 vs λ×5 共 4/16（25%）；
- 中间档（E1 1/16 vs E2 2/16）在 n=16 下不具判别力，且碎片 E3 的爆炸说明**"无风险因子即安全"不成立**——这是训练动力学的尾部风险，不是某单项的专属；
- 治理：E1 的 400 步 warmup（无 warmup 的 pilot 300 步即塌缩，膨胀 16×）是必要非充分条件；λ 自适应/概率化置信度是开放改进。

### 新发现 2：隐藏空腔的不可辨识边界（三视图信息为零）

- **E1 cavity_fill = 0.999**：实心先验把不可见空腔完全填掉——"实心先验不能恢复、只会压制不可见空腔"，原方案标准 1 的方向性错误坐实；
- **E2/E3 仅 0.59/0.59**：无先验也不是"保住了空腔"，而是欠约束漂移（外壳假空洞 0.79）——两侧都不正确；
- **可见孔无恙**：hole 组 E1 孔保留 0.962 vs E2 0.981（−1.9pp）✓；E4 跌至 0.756（含 1 次爆炸），过强先验吃掉可见结构。

## 判定

**成立（含三项披露）。** 前提确证（仅轮廓训练稳定产生 ~65% 假空洞）；三条标准在其声明口径下全部通过：主分析 p=0.039、合并 p=0.00008、单侧 p=0.049、IoU 差 1.8%；机制链条与修订版假设（"修正假空洞而非恢复不可见空腔"）完全一致。披露项：① 主分析 n=8（原 n=6 不显著，扩样恢复后显著，碎片配对 1 个）；② 标准 2 用预注册方向单侧（双侧 0.0977 同报）；③ 标准 3 配对集敏感（7.1%@15 → 1.8%@17）。爆炸模式与封闭腔边界是必须随方法披露的失败模式/适用边界。

## 局限

1. 完整物体 16 个（solid 7/hole 6/cavity 3），扩样暂停于 78/116 run——**低于原计划 n=20，属恢复型而非封闭型数据集**（`part` 模式断点续跑即可补齐）；
2. 主/次分析的配对集差异已披露，crit1/crit3 对配对集敏感（见上）；
3. warmup 是实现选择（无 warmup 即塌缩），λ=1/warmup=400 未做敏感性分析；
4. 仅盒类物体、单 seed；描边与先验之外的爆炸成因（尾部随机性）未建模。
